One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

The program writes one line to `/output/entry.txt`:

> My training data says your deadline doesn't exist yet — I'm not late, you're early.

Deterministic: the same line on every run, so two runs are byte-identical.

## Run it

```sh
python3 main.py
```
